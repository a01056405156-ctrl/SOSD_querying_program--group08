# SOSD 데이터 검색 프로그램 - 8조

## 1. 프로젝트 소개

본 프로그램은 SOSD(SOSD Benchmark) 데이터셋에서 정수 데이터를 빠르게 검색하기 위해 C++로 구현한 프로그램입니다.

Radix Index와 이진 탐색(Binary Search)을 함께 사용하여 검색을 수행합니다.

## 2. 개발 환경

- 개발 언어: C++20
- 개발 도구: Visual Studio Code
- 컴파일러: g++ (MinGW-w64)
- 운영체제: Windows

## 3. 사용한 자료구조 및 알고리즘

Radix Index를 사용하여 검색 범위를 줄이고, 해당 범위에서 이진 탐색을 수행합니다.

정렬된 데이터의 특성을 이용하여 검색 범위를 빠르게 찾을 수 있도록 구현하였습니다.

## 4. 컴파일 방법

PowerShell 터미널에서 다음 명령어를 실행합니다.

```powershell
g++ -std=c++20 -O2 -Wall -Wextra main.cpp -o main.exe -lpsapi
```

## 5. 실행 방법

### 실제 SOSD 데이터셋 실행

```powershell
.\main.exe .\uniform_dense_200M_uint32
```

데이터 파일은 실행 폴더에 별도로 준비해야 합니다.

### 테스트 데이터 실행

```powershell
.\main.exe --test 1000000
```

프로그램 실행 후 검색할 정수를 입력할 수 있으며, `q`를 입력하면 종료됩니다.

## 6. 성능 테스트 결과

## 7. 참고 사항

- SOSD 데이터셋은 정렬된 `uint32` 형식이어야 합니다.
- 데이터 파일은 크기가 크기 때문에 GitHub에 포함하지 않았습니다.
- 프로그램은 Windows 환경을 기준으로 작성되었습니다.
- 512 MiB의 프로세스 private memory 제한을 적용하도록 구현하였습니다.
