# SOSD 검색 프로그램 사용법

## 실행 방법

1. Visual Studio C++ 콘솔 프로젝트의 소스 파일을 `main.cpp`로 교체합니다.
2. 빌드 구성을 **Release / x64**로 설정합니다. C++14 이상을 사용합니다.
3. **Ctrl + F5**로 프로그램을 실행합니다. 명령 인수 설정은 필요 없습니다.
4. 안내에 따라 압축을 푼 데이터 파일의 전체 경로를 입력합니다.

   ```text
   D:\SOSD\uniform_dense_200M_uint32
   ```

5. 준비가 완료되면 검색할 정수(0~4294967295)를 입력하고 Enter를 누릅니다.
6. 다른 숫자를 입력해 반복 검색할 수 있습니다. **q**를 입력하면 시간 합계를 출력하고 종료합니다.

`uniform_dense_200M_uint32`와 `uniform_sparse_200M_uint32`는 각각 프로그램을 실행해 별도로 테스트합니다. 파일 경로는 실제 저장 위치에 맞게 변경하세요.

## 결과 확인

| 출력 항목 | 의미 |
|---|---|
| 인덱스(0부터) | 원본 데이터에서 0부터 세는 위치 |
| 순번(1부터) | 원본 데이터에서 몇 번째인지 표시 |
| 검색 시간 | 방금 입력한 키의 검색 시간, 마이크로초(μs) 단위 |
| 구축 시간 | 파일 열기와 표본 인덱스·캐시 준비 시간, 초 단위 |
| 전체 검색 시간 | 성공·실패한 검색 시간의 합, 초 단위 |
| 구축 시간 + 전체 검색 시간 | 구축과 검색 시간의 합, 초 단위 |

없는 값은 없다고 안내하며, 중복 값은 첫 번째 위치를 반환합니다. 입력 대기와 결과 출력 시간은 검색 시간에 포함하지 않습니다. Visual Studio의 컴파일·링크 시간은 별도입니다.

## 참고

- Windows x64용이며 검색 프로그램의 메모리 제한은 **512MiB**입니다.
- 압축을 푼 **오름차순 SOSD uint32 바이너리 파일**을 사용하세요.
- 실행 중 데이터 파일을 수정하지 마세요.
- 경로를 잘못 입력하면 다시 입력할 수 있습니다. 한글 경로에서 열리지 않으면 영문 경로로 옮겨 실행하세요.
